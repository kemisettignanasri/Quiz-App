# 📱 Quiz App

An Android-based multiple-choice quiz application developed using **Java and Android Studio**. The application allows users to register, sign in, choose a programming or technical subject, answer quiz questions, and view their results.

## ✨ Features

- **User Authentication:** Sign-up and sign-in using Firebase Authentication.
- **Multiple Quiz Subjects:** Java, Kotlin, Python, C, C++, Dart, SQL, and XML.
- **Subject-Specific Questions:** Each subject has its own question bank with four options per question.
- **Answer Validation:** Automatically checks selected answers against the correct answers.
- **Score Tracking:** Tracks correct and incorrect answers during a quiz.
- **Question Navigation:** Displays questions one at a time and allows users to proceed to the next question.
- **Result Screen:** Displays the number of correct answers, incorrect answers, and attempted questions.
- **Theme Support:** Supports light and dark themes.
- **Timer-Free Quizzes:** Questions can be answered without a quiz countdown timer.
- **Sign Out:** Allows users to sign out of their account.

## 📚 Quiz Subjects

The application includes multiple-choice questions covering:

- Java
- Kotlin
- Python
- C
- C++
- Dart
- SQL
- XML

Each question provides four answer options, and the application compares the selected option with the stored correct answer.

## 🔄 Application Flow

1. Launch the application.
2. Register or sign in.
3. Open the home screen.
4. Select a quiz subject.
5. Answer the questions.
6. View the final quiz results.
7. Return to the home screen.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Configure Firebase if required, using your own Firebase project configuration.
5. Run the application on an Android emulator or compatible Android device.
